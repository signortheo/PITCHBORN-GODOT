# PITCHBORN — Godot Prototype

Nuova versione giocabile di PITCHBORN costruita in Godot.

## Prima build
- campo 105x68 m
- giocatore 3D controllabile
- telecamera terza persona
- pallone fisico
- possesso/dribbling
- passaggio
- tiro caricabile
- sprint e stamina
- porte
- HUD e reset

## Controlli
WASD movimento · Shift sprint · J passaggio · K tiro · R reset

Apri `project.godot` con Godot 4 e premi F6/F5.
